# Add a Proof

1. Identify the roadmap exit criterion and choose `<module>/<behavior>`.
2. Register the scenario and stable structured event; never assert human log wording.
3. Add success and relevant failure behavior with bounded readiness and timeout.
4. Run repeatedly, update the roadmap proof entry, and retain completed v1 proofs.
